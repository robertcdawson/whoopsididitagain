# whoopsididitagain

A personal, single-user app built on the [WHOOP API](https://developer.whoop.com/).

It is a hobby project that pulls one person's own sleep, recovery, strain, and
workout data — mine. It is not a product, it has no sign-up, and it is not
affiliated with WHOOP, Inc.
